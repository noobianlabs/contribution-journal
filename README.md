# Open-source contribution journal

Daily research for [noobianlabs](https://github.com/noobianlabs), focused on TypeScript, JavaScript, AI tools, and community software.

Entries record real, checked opportunities and a practical next step. Research entries are not claims that code was contributed to the listed projects.

## Daily workflow

- Find up to three open, unassigned issues in licensed, non-archived projects.
- Read the issue and contribution rules; check for existing pull requests or someone already working on it.
- Record why the task fits, its scope, and how to verify a fix.
- Commit new research once per day. Skip when there is nothing useful to add.
